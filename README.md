## Основные направления

## Проекты

### Выявление атак на аккаунты (Account Takeover Fraud)

SQL-проект, направленный на выявление признаков компрометации аккаунтов в транзакционных данных.  
Анализ включает обнаружение поведенческих аномалий: увеличение частоты операций, нетипичные суммы, 
возобновление активности после периода неактивности и повышенное количество попыток входа.

**Инструменты:** SQL, MySQL, CTE, оконные функции, risk scoring  

---

### Анализ восприятия коррупции и безопасности в Гонконге

Статистический анализ данных World Values Survey для изучения взаимосвязи между восприятием коррупции, 
ощущением безопасности и защитным поведением.

**Инструменты:** R, логистическая регрессия, линейная регрессия, статистический анализ  

---
